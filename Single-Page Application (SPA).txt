Single-Page Application (SPA)
--------------------------------------------------------------------------------------------------------------
--------------------------------------------------------------------------------------------------------------
Section 1: Intro, Theory & Tools
      & 2: Building the front end - HTML, CSS & jQuery:

Defintion: Entire app is only single page w/ content replaced as needed

Advantages: a) fluid user experience
	    b) faster
	    c) less bandwidth (loading only small part of page)

How does it work?
1) option 1: load complete HTML, make diff parts visible - use if you have big project, many differences per update
2) option 2: load only HTML parts, replace parts in container - use if you don't have large # of diffs per update


Begin setting up app: (.Net Framework 4.8.1 !! lol)
1) create new ASP.Net Web Application project w/ 'Empty' template and check box: Web API, No Auth
2) Note: folders 'Controllers' and 'Models' will be used by Web API
3) Create new HTML page called 'index.html' in project
4) in 'index'html' add text in 'body', and run > File-View in Browser(google chrome)
5) Create new jquery script file > app.js
6) Add styles.css, jquery-3.7.1.min.js, & app.js as references to index.html's head section
7) install JQuery nuget pkg

See code for index.html, app.js, styles.css
